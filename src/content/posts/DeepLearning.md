# 术语：
核心知识点：
神经网络中的激活项通常写作 $a_{i}^{(l)}$ ，其中：
- 上标 $(l)$ : 代表层数 (Layer)。
- 下标 $i$ ：代表该层中的第几个神经元。
- 权重 $\Theta^{(l)}$ ：代表连接第 $l$ 层和第 $l + 1$ 层的权重。
1. 神经元表示法（图二）与下标含义
在神经网络中， $\Theta_{i,j}^{(l)}$ 这种写法看起来很头疼，但其实有一个固定的记忆规律。
以公式 $\mathbf{A}$ 为例： $a_1^{(3)} = g\big(\Theta_{1,0}^{(2)}a_0^{(2)} + \Theta_{1,1}^{(2)}a_1^{(2)} + \Theta_{1,2}^{(2)}a_2^{(2)}\big)$ 
- 上标 $(l)$ ：代表出发层。 $\Theta^{(2)}$ 表示这一组权重是用来连接第 2 层和第 3 层的。
- 下标第一个数字 $i$ ：代表目标神经元的索引（第 $l + 1$ 层的第几个）。
- 下标第二个数字 $j$ ：代表来源神经元的索引（第 $l$ 层的第几个）。
为什么这么排？为了方便矩阵乘法。这样安排可以让权重矩阵 $\Theta$ 直接乘以激活向量 $a$ ，得到下一层的输出。即 $a^{(l+1)} = g(\Theta^{(l)} a^{(l)})$ 。

# 激活函数
激活函数就是输出激活值的函数，也就是每个神经元内计算参数的函数，为神经网络带来了非线性能力。一开始的时候并不想传统机器学习会自己设置多项式，来实现非线性，而是在神经元中添加激活函数来实现非线性。

# 1. Sigmoid
公式： $f(z) = 11 + e - zf(z) = 1 + e - z1$ 
- 特点：将输入压缩到 $(0,1)$ 之间。常用于二分类问题的输出层。容易导致梯度消失问题。
- 图像：平滑的S型曲线。
# 2. ReLU (整流线性单元)
- 公式： $f(z) = \max(0, z)f(z) = \max(0, z)$ 
- 特点：计算简单，能有效缓解梯度消失问题，是目前最常用的隐藏层激活函数。
- 图像：在原点处转折的折线，负数输出0，正数原样输出。
# 3. 线性激活函数 (Linear activation function)
g（z）=z相当于没用激活函数，直接就是线性回归函数

# 如何选择隐藏层适合的激活函数
# a. 输出层根据结果去选择：
1.二类结果，sigmoid
2. 结果有正有负, 线性激活=没有激活函数
3.结果只有正数，没有负数，ReLU(整流线性单元)
# b. 隐藏层选择:
ReLU(整流线性单元)最常用（默认使用）
因为 sigmoid 会在两边都有平的区域，会使得梯度变得较小的地方多，这样会使梯度下降的比较慢。
不要在隐藏层中使用线性激活函数
# 激活函数的意义
如果在神经网络中所有的神经元都使用线性激活函数，也就是不使用其他的激活函数，最终整个函数其实就是线性回归函数，如果输出层用的是逻辑回归，最终的整个函数就是逻辑回归函数，和原来的机器学习并无区别，不能发挥神经网络的作用，拟合的效果不会高，所以要用其他的激活函数，让曲线去更能拟合数据，每一层的结果作为输入到下一层，相当于复合函数相互嵌套，拟合能力非常强。

# 模型（宏观上的）：
- 前向传播：数据从输入层，经过隐藏层，最终到达输出层，并产生预测结果的过程。这是一个推理过程。
- 反向传播：根据前向传播产生的预测结果与真实值之间的误差，从输出层开始，反向逐层计算每个参数（权重和偏置）对总误差的"贡献"大小（即梯度），并据此更新参数。这是一个学习过程。
