深度学习（神经网络）笔记 

**记录日期：** 2026年1月18日 

## 1. 核心思想与背景

* 神经网络曾经是根据大脑的工作原理去模仿和设计的，但后来慢慢变成了工程化的思想去实现 。


* 尽管人类尚未完全清楚大脑的工作原理，未来的研究或许会有所启发，但目前大多数研究仍在工程化的方向前进 。


* 庞大的数据量对神经网络的性能有很好的提升作用，而传统的逻辑回归和线性回归则无法很好地实现这一点 。因此，随着互联网时代数据量的增加，神经网络逐渐风靡 。


* 神经网络自己进行特征值的选择和内部函数的设计，而不是人为配置的，这与之前的方式完全不同 。



## 2. 核心知识点与数学符号


**激活项：** 神经网络中的激活项通常写作 $a_{i}^{(l)}$ 。


* 上标 $(l)$：代表层数（Layer） 。


* 下标 $i$：代表该层中的第几个神经元 。

**权重：** 权重 $\Theta$ 代表连接第 $l$ 层和第 $l+1$ 层的参数 。


**公式示例与下标含义：** 以公式 $a_{1}^{(3)}=g(\Theta_{1,0}^{(2)}a_{0}^{(2)}+\Theta_{1,1}^{(2)}a_{1}^{(2)}+\Theta_{1,2}^{(2)}a_{2}^{(2)})$ 为例 。


* 上标 $(2)$：代表出发层，表示这一组权重是用来连接第2层和第3层的 。


* 下标第一个数字：代表目标神经元的索引（第 $l+1$ 层的第几个） 。


* 下标第二个数字：代表来源神经元的索引（第 $l$ 层的第几个） 。


* 这种排版设计是为了方便矩阵乘法，使得权重矩阵可以直接乘以激活向量 $a^{(l)}$ 得到下一层的输出，即 $a^{(l+1)}=g(\Theta^{(l)}a^{(l)})$ 。

## 4. 神经层（Layer）

* 层是一组相关或者相同的神经元的组合，分别获得输入并且输出一些数据 。输出的结果被称为激活值，用以下一层神经元的输入 。


* 一层可以有多个神经元或者就一个神经元 。通常分为输入层，隐藏层，输出层 。


* 一般输入层被称为第0层，其他的隐藏层和输出层分别会占用一个数字，表示自己的层数 。


* **常见层的类型：**
* 
**Dense 层（全连接层）：** 每个层的输出都会成为下一个层的输入 。


* 
**卷积层（Convolutional）：** 每个层会看输入层的一部分，而不是像 dense 层的那种前向传播模型 。


* 其他还包括 transformer model、LSTM (Long Short Term Memory) model 以及注意力模型 (attention model) 。





## 5. 激活函数（Activation Function）

* 激活函数就是输出激活值的函数，为神经网络带来了非线性能力 。它不再像传统机器学习那样自己设置多项式来实现非线性，而是在神经元中添加激活函数来实现 。



### 常见的激活函数


**线性激活函数 (Linear)：** $g(z)=z$ 。相当于没用激活函数，直接就是线性回归函数 。



**Sigmoid 函数：** $g(z)=\frac{1}{1+e^{-z}}$ 。



**特点：** 将输入压缩到 $(0,1)$ 之间，常用于二分类问题的输出层 。容易导致梯度消失问题 。



**图像：** 平滑的S型曲线 。





**ReLU (整流线性单元)：** $g(z)=\max(0,z)$ 。



**特点：** 计算简单，能有效缓解梯度消失问题，是目前最常用的隐藏层激活函数 。



**图像：** 在原点处转折的折线，负数输出0，正数原样输出 。





**Tanh (双曲正切) 函数：** $tanh(x)=\frac{1-\exp(-2x)}{1+\exp(-2x)}$ 。



**特点：** 与 sigmoid 函数类似，但能将其输入压缩转换到区间 $(-1,1)$ 上 。





### 激活函数的选择策略


**输出层：** 二类结果使用 sigmoid ；结果有正有负使用线性激活 ；结果只有正数使用 ReLU 。



**隐藏层：** 最常用（默认使用）ReLU 。因为 sigmoid 会在两边都有平的区域，使得梯度变小的地方多，导致梯度下降比较慢 。不要在隐藏层中使用线性激活函数 。



**核心意义：** 如果所有神经元都使用线性激活函数，最终整个函数其实就是线性回归或逻辑回归函数，和原来的机器学习并无区别 。使用其他激活函数让曲线更能拟合数据，每一层结果作为下一层输入，相当于复合函数相互嵌套，拟合能力非常强 。



## 6. 模型运作与高级优化


**前向传播：** 数据从输入层，经过隐藏层，最终到达输出层，并产生预测结果的过程，这是一个推理过程 。可以利用硬件实现矩阵乘法快速计算 。



**反向传播：** 根据前向传播产生的预测结果与真实值之间的误差，从输出层开始，反向逐层计算每个参数（权重和偏置）对总误差的“贡献”大小（即梯度），并据此更新参数，这是一个学习过程 。


* **多类 (Multiclass) 与 Softmax：**
* Softmax 函数是对逻辑回归的一种拓展，用于实现多类别的分类问题 。


* 它利用线性回归定义 $z$，输入到函数得到每个类别的 $e$ 值，所有类别的 $e$ 值的和为分母，计算出的 $a$ 为最终结果，所有的 $a$ 的和的值为1 。




* **交叉熵代价函数 (Crossentropy)：**
* 公式核心为 $loss=-\log(a_{j})$ （当 $y=j$ 时） 。


* 尽可能的想让 $a_{j}$ 靠近1，这样 loss 等于0，误差最小 。在 TensorFlow 中被称为 Sparse Categorical Crossentropy（稀疏类别交叉熵函数） 。




* 
**Adam 优化器：** (Adaptive Moment estimation) 可以动态的调整学习率 。如果进度缓慢就会调大学习率，如果参数来回动荡就会调小学习率，并且对每个参数可以有自己的学习率，让梯度下降更快 。



## 7. 评估模型的性能

* 划分训练集，一部分用来训练（70%），一部分测试（30%） 。


* 
$j.train$：误差函数在训练数据上的表现，即模型结果很靠近训练数据 。


* 
$j.test$：误差函数在测试数据（未训练的）上的表现，即模型预测真实数据的能力 。即使模型对训练数据拟合得很好，预测能力也不一定很好 。

**题目：** 考虑一个二值输入 $x_{1}, x_{2} \in \{0,1\}$ 的神经网络神经元，其加权和公式为 $z = -20 + 30x_{1} + 30x_{2}$ 。搭配 Sigmoid 激活函数，它近似计算了哪种逻辑函数？ 

**计算过程：**
当 $z \ge 0$ 时输出接近 1，当 $z < 0$ 时输出接近 0 。

0,0,−20+30(0)+30(0)=−20 ,0 (因为 z<0) 
0,1,−20+30(0)+30(1)=10 ,1 (因为 z>0) 
1,0,−20+30(1)+30(0)=10 ,1 (因为 z>0) 
1,1,−20+30(1)+30(1)=40 ,1 (因为 z>0)
